# Rust AK-47 (Fabric 1.16.5)

## Что внутри
- **АК-47** (`rustak:ak47`) - автоматический огонь по зажатой **ЛКМ** (как в Rust), ~400 выст/мин, хитскан на 120 блоков, хедшот x2, разброс (присед точнее, в прыжке хуже), дым/пламя/частицы попаданий.
- **Патроны 7.62x39** (`rustak:ammo_762`) - расходуются из инвентаря, в креативе бесконечные. Остаток показывается над хотбаром.
- **Новый звук выстрела** - 3 варианта (`sounds/ak47_shot1..3.ogg`), синтезированы скриптом, играются случайно.
- **Руки как в Rust** - свой рендер от первого лица: автомат по центру-справа, ОБЕ руки на оружии (правая на рукояти, левая под цевьём), откат модели + подброс камеры при стрельбе.
- Крафты: АК - `III / WRI / W__` (I - железо, W - доски, R - редстоун); патроны - порох + железный самородок + золотой самородок = 8 шт.

## Сборка
1. JDK 16 или 17.
2. Откройте папку в IntelliJ IDEA (импорт Gradle подтянет Gradle 7.3.3 по `gradle-wrapper.properties`)
   или, если Gradle установлен: `gradle wrapper --gradle-version 7.3.3`, затем `./gradlew build`.
3. Готовый мод: `build/libs/rustak-ak47-1.0.0.jar`. Нужен Fabric Loader 0.14+ и Fabric API 0.42.0+1.16.
4. Тест: `./gradlew runClient`.

## Что подкручивать
Положение автомата и рук - константы в начале `client/Ak47ViewModel.java`
(`GUN_X/Y/Z`, `GUN_SCALE`, `R_HAND/R_DIR/R_ROLL`, `L_HAND/L_DIR/L_ROLL`).
Вид от третьего лица и иконка - `models/item/ak47.json` (`display`), удобнее править в Blockbench.
Скорострельность/урон - `Ak47Item.FIRE_DELAY`, `DAMAGE`.

## Свои ассеты
Заменяйте файлы 1-в-1: `textures/item/ak47.png`, `models/item/ak47.json`, `sounds/ak47_shot*.ogg` (моно, ogg vorbis).
Оригинальные модели/звуки Rust защищены авторским правом, поэтому в моде свои самодельные.
